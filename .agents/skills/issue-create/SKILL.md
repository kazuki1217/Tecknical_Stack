# GitHub Issueを作成する

## 手順

1. 依頼内容と関連ファイルを確認する。
2. 推測でIssueを作らず、不明点があれば利用者に確認する。
3. 既存Issueを確認し、重複や関連Issueがないか確認する。
4. 重複があれば、原則として新規作成せずURLを示す。
5. 簡潔な日本語タイトルと本文を作る。

```markdown
## 背景・課題

## 対応内容

## 受け入れ条件
- [ ] 検証可能な条件を記載する

## 動作確認
- 確認した操作、コマンド、テストを記載する

## 補足
```

5. Issueを作成する前に必ず草案を提示し、利用者の承認を得る。
6. 作成したIssueの番号とURLを返す。

秘密情報や個人情報は記載しない。

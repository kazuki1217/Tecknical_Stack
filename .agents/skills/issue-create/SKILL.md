# GitHub Issueを作成する

## 手順

1. 依頼内容と関連ファイルを確認する。
2. 推測でIssueを作らず、不明点があれば利用者に確認する。
3. 既存Issueを確認し、重複や関連Issueがないか確認する。
4. 重複があれば、原則として新規作成せずURLを示す。
5. 簡潔な日本語タイトルと本文の草案を作る。タイトルの先頭には `[作成者<エージェント名>] ` を付ける。エージェント名は実際に作業しているAI（例: Claude、Codex）の名前にする（例: `[作成者Claude] スマホ・タブレットで画面が見づらい（レスポンシブ対応の不足）`）。本文は細かく書きすぎない。

```markdown
## 背景・課題

## 対応内容

## 補足
- 必要に応じて記載
```

5. 草案を提示し、利用者の承認を得る。
6. 作成したIssueの番号とURLを返す。

秘密情報や個人情報は記載しない。

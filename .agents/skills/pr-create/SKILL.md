# Draft PRを作成する

## 手順

1. 対象Issue、現在のブランチ、差分を確認する。
2. 無関係な変更がなく、必要な検証が成功していることを確認する。
3. 内容が伝わるコミットメッセージをコミットし、ブランチをpushする。
4. 次の内容を含むDraft PRを作成する。

```markdown
## 概要

## 変更内容

## 確認結果

Closes #Issue番号
```

5. PRのURLと、レビュー時に見るべき点を返す。

## 制約

- テスト失敗や未解決の問題を隠さない。
- 認証や権限が不足している場合は停止する。
- PRをReady状態にせず、マージもしない。
